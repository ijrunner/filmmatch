# 达芬奇质感搭建指南（免费版可用 · F13 图文兜底）

- 面向：达芬奇（Resolve）免费版用户，没有调色经验也能照做。
- 目标：把 FilmMatch 工作台导出的 `.cube` 色彩层挂上，并用免费版可用的节点/窗口/Fusion 手工搭出「光晕 / 柔光 / 暗角 / 颗粒」质感层。
- 单位约定与工作台一致：**半径 = 画面高度%（%H）**，颗粒尺寸 = 画面高度‰。换算：`像素 = H × 数值`（1080p：1 %H = 10.8px、1 ‰H = 1.08px；2160p：1 %H = 21.6px、1 ‰H = 2.16px）。
- 同一内容的精简版内嵌在工作台「指南」抽屉（`app/src/ui/guide.ts`），改文档时同步该文件。

## 0. 开始前准备（1 分钟）

1. 工作台 ⑤ 导出 `.cube`（65³，文件名即配方码）。
2. 达芬奇顶部菜单 **Color → Open LUT Folder**（直接打开 LUT 目录），把 `.cube` 拷进去。
   - Windows：`C:\ProgramData\Blackmagic Design\DaVinci Resolve\Support\LUT`
   - macOS：`/Library/Application Support/Blackmagic Design/DaVinci Resolve/LUT`
   - Linux：`~/.local/share/DaVinciResolve/LUT`
3. 重启达芬奇（或在 Color 页节点右键 → LUT 列表刷新）。
4. 确认时间线色彩空间为 Rec.709 / Gamma 2.4（工作台按 Rec.709 截图处理，空间不一致会发灰）。

## 1. 节点树总览（10 分钟照做）

```
源 → B1 挂LUT → B2 光晕 → B3 柔光 → B4 暗角 → B5 颗粒(Fusion叠加) → 输出
      色彩层     亮通+模糊+Screen  同理更大半径   PowerWindow    顶层噪点
```

### 第 1 步 · 挂 LUT（B1，色彩层）
1. 选中片段进入 Color 页，选中 01 号节点。
2. 节点右键 → **LUT** → 展开列表找到你拷入的 `FM-XXXX.cube`。
3. 对比工作台预览：肤色/夜色方向一致即成功。LUT 已包含「色彩匹配 ∘ look」全部色彩，B1 不用再调。

### 第 2 步 · 光晕（B2）
原理：提取高光 → 高斯模糊 → Screen 叠回（暗部不受污染）。免费版全节点可实现：

1. 新建串行节点 B2。先把**高光提出来**：曲线页勾选右上 **Soft Clip（K/C）**，把高光裁剪点拉到工作台「阈值」×100（如 0.55 → 55）；再在暗端把 Soft Clip 压死，让 B2 只剩亮部信号。
2. **Blur 页 → Gaussian Blur**，半径按对照表（表 1）。
3. **Key 页 → Composite mode 选 Screen**（或 Lighten），**Key Output Gain = 晕强度**：`Gain ≈ 0.75 × 工作台「强度」`（如 0.42 → 31%）。
4. **染成橙红**：仍在 B2，把 Gain 通道微调为 R +20% / G 0% / B −15%（等效工作台 tint [1.0,0.31,0.19]）。
5. 1:1 检查灯牌/路灯：亮部周围有渐变橙晕、暗部黑位不变灰。

### 第 3 步 · 柔光（B3）
与第 2 步同结构，参数不同：阈值 85（0.85×100）、半径更大（默认 2 %H）、Gain 更低（`0.25 × 强度` 起步）。作用是高光「化开」产生空气感，别调成第二层光晕。

### 第 4 步 · 暗角（B4）
1. 新建节点 B4 → Window 面板选**圆形窗口** → 勾选 **Inverse（外部）**。
2. Softness 拉到 60–75（边缘过渡柔和，无硬边）。
3. 给**窗口外部**降 Gamma： Gamma ≈ −(暗角强度) 起步（如 0.25 → −0.25），目标：四角比中心暗约「暗角强度×100%」，中心 100% 不动。
4. 工作台的「边缘色散」免费版无节点级等效（需 Studio 或第三方 OFX），量级很小（角落约 3–4px），可忽略。

### 第 5 步 · 颗粒（B5 / Fusion）
免费版没有 Film Grain 类 ResolveFX（需 Studio），用 Fusion 的 FastNoise 等效：

1. 选中片段右键 → **New Fusion Composition**（或在 B5 后用 Fusion 效果蒙版太绕，推荐顶层合成方案：媒体池新建 Fusion 合成，时长对齐片段，拖到视频 2 轨）。
2. Fusion 页：`FastNoise → Merge（前景接 FastNoise，背景接 MediaIn）`。
3. FastNoise：Contrast 拉高让噪声呈黑白絮状；**Detail** 降低（絮块变大）；Lock XY，用 **Seethe Rate ≈ 0.4–0.8** 让颗粒「活着」（等效工作台 24fps 步进，避免死图）。
4. Merge：**Operator = Soft Light（或 Overlay）**，**Blend = 颗粒强度**：`Blend ≈ 14% × √(ISO/400)`（ISO400 → 14%，ISO1600 → 28%）。
5. 颗粒粗细按表 1 目检：1:1 放大，颗粒间距 ≈ 表中像素。

### 表 1 · 工作台参数 → 达芬奇节点参数对照

| 工作台参数 | 默认值 | 达芬奇位置 | 1080p 示例 | 2160p 示例 |
|---|---|---|---|---|
| 光晕 半径（%H） | 1.2–2.8 | B2 Gaussian Blur Radius | 13–30px（晕直径≈2×） | 26–60px |
| 光晕 强度 | 0.42 | B2 Key Output Gain | ≈ 31% | 同左（与分辨率无关） |
| 光晕 阈值 | 0.55–0.75 | B2 Soft Clip 高光裁剪点 | 55–75 | 同左 |
| 柔光 半径（%H） | 1.6–2.5 | B3 Gaussian Blur Radius | 17–27px | 35–54px |
| 柔光 阈值 | 0.85 | B3 Soft Clip | 85 | 同左 |
| 暗角 强度 | 0.18–0.30 | B4 窗口外部 Gamma | −0.18 ~ −0.30 | 同左 |
| 边缘色散 | 0.004 | （免费版无等效，忽略） | 角落 ≈ 4px | 角落 ≈ 9px |
| 颗粒 ISO | 400 | Merge Blend | 14%（√ 响应：1600 → 28%） | 同左 |
| 颗粒 尺寸（‰H） | 1.0–1.6 | FastNoise Detail/Scale | 间距 ≈ 1.1–1.7px | 2.2–3.5px |

> 达芬奇 Blur 的 Radius 滑杆是内部归一值，先按像素换算列设置数量级，再 1:1 目检微调；强度/阈值类参数与分辨率无关，直接用。

### 第 6 步 · 验收（2 分钟）
1. 灯牌 1:1：晕从亮部边缘向外 ≥2 个亮阶渐变、无硬边。
2. 黑位：暗部颗粒「絮状、活的」，黑位不发灰（Screen 层暗部应接近纯黑）。
3. 四角：暗角平滑、中心不动。
4. 满意后：图库右键 → Grab Still 保存，或把 B1–B4 存成自己的 PowerGrade 复用。

## 1.5 一键生成「你的配方」的搭建清单（R5 新增）

工作台 ⑤「节点包导出」区（或顶栏「指南」抽屉第 ⑧ 节）现在可以**按当前配方自动生成搭建清单**：
- **下载搭建清单.md**：本指南的「按你的配方填好参数」版本——逐节点列出节点名、参数值、混合模式与不透明度，末尾附 1080p / 2160p 像素换算表（光晕紧晕/宽晕半径、柔光半径、颗粒间距、边缘色散），照做即可，不必自己换算。
- **下载参数对照表.md**：逐段/逐参数的数值速查表。
- **下载 .drx（实验性）**：达芬奇 PowerGrade 的**实验性**模板，**尚未在达芬奇实测**（spike① 未回执），导入前请先备份工程；正式交付请用搭建清单手工搭。
- 节点顺序固定为：**LUT/风格层 → 光晕 → 柔光 → 颗粒 → 暗角 → 合成**；清单里关闭的层会标注「已关闭（可跳过）」。

## 2. 常见问题

- **LUT 列表里找不到**：目录不对（注意 ProgramData 是隐藏目录）或没重启；用 Color → Open LUT Folder 核对。
- **挂 LUT 后发灰/偏色**：时间线色彩空间不是 Rec.709 / Gamma 2.4；或素材是 Log 未正常转换。
- **光晕把画面抬灰**：B2 的 Soft Clip 暗端没压死（Composite 进来的暗部不是纯黑），或阈值过低。
- **颗粒像电视雪花**：Detail 太高/Seethe Rate 太高——絮块要大、演化要慢；Blend 别超过 30%。
- **4K 时间线观感和预览不一样**：半径类参数没按画面高度换算（用表 1 的 2160p 列）。
- **能直接导入 .drx 吗**：暂不建议。PowerGrade 的 .drx 为达芬奇私有格式（可能是编译后的脚本），本工作台导出的是**实验性模板**、未实测；质感层请优先用本指南的节点树手工搭建，或用 ⑤「节点包导出」的**一键搭建清单**（spike① 回执后评估把 .drx 生成器升级为主交付）。
